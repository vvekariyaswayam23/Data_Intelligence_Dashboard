## 📝 About the Project

The **Data Intelligence Dashboard** is an Excel-based data analytics project designed to explore customer transactions, evaluate sales performance, and present important business metrics in an interactive, easy-to-understand dashboard.

The project uses transaction-level data to analyze revenue, products, regions, payment methods, and customer segments. It combines spreadsheet analysis, formulas, visualizations, what-if scenarios, and a summary report to support data-driven decisions.

## 🎯 Project Objectives

- 📌 Analyze overall revenue and transaction performance.
- 👥 Understand customer purchasing behavior and identify top customers.
- 🛍️ Compare product and category performance.
- 🌍 Evaluate sales across different regions.
- 💳 Compare revenue by payment method and customer segment.
- 📈 Present findings through charts, KPI indicators, and a dashboard.
- 🧪 Explore business scenarios using What-If Analysis and linear regression.

## 📊 Dataset Overview

The dataset contains **250 transaction records** and **14 fields** covering transaction, product, customer, and sales information.

| Column | Description |
|---|---|
| `Transaction_ID` | Unique transaction identifier |
| `Date` | Transaction date |
| `Customer_ID` | Customer identifier |
| `Customer_Name` | Customer name |
| `Product_ID` | Product identifier |
| `Product_Name` | Name of the purchased product |
| `Category` | Product category |
| `Quantity` | Number of units purchased |
| `Unit_Price` | Price per unit |
| `Payment_Method` | Method used for payment |
| `Region` | Sales region |
| `Customer_Segment` | Customer segment classification |
| `Customer_Since` | Date the customer relationship began |
| `Total_Amount` | Total value of the transaction |

## 🔍 Key Findings

Based on the workbook's report and dashboard:

- 💰 **Total revenue:** approximately **$229,192**.
- 🧾 **Transactions:** **250**.
- 🛒 **Average order value:** approximately **$917**.
- 👤 **Customers:** approximately **50**.
- 🏆 **Top region by revenue:** **East**, with approximately **$59,288**.
- 📉 **Lowest region by revenue:** **South**, with approximately **$36,399**.
- 💻 **Highest-revenue product:** **Laptop**.
- 🧩 **Leading category:** **Electronics**, contributing the largest share of revenue in the dashboard.

*Values are rounded for readability and reflect the current workbook calculations.*

## 💡 Business Recommendations

- 📦 Explore product bundles across categories to encourage cross-selling.
- 📊 Review the dashboard regularly to monitor KPIs and compare business scenarios.

## 🚀 How to Use

1. Download or clone this repository.
2. Open `Data_Intelligence_Dashboard.xlsx` in Microsoft Excel.
3. Review **Raw Data** to understand the source transactions.
4. Explore **Analysis** and **What-If & Regression** to review calculations and scenarios.
5. Open **Dashboard** to view the KPIs and charts.
6. Read **Report** for the summarized insights and recommendations.

> ℹ️ Some workbook features, formulas, or interactive elements may behave differently in other spreadsheet applications. Microsoft Excel is recommended for the best experience.
